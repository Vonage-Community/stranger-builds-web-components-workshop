
# Stranger Builds Web Components Workshop

This repository is for the participants of the [Nerdconf's Stranger Builds Hackathon](https://strangerbuilds.com/).

## Get started

The easiest way to run this application is by using GitHub Codespaces. This sets up the entire environment automatically in your browser.

> Note: For best results, please use the Chrome browser. Other browsers may not load properly.

1. **Fork this repository** to your own GitHub account.
2. In your new fork, click the green **<> Code** button at the top right of the files list.
3. Select the **Codespaces** tab.
4. Click **Create codespace on main**.

While the Codespace is loading (can take a couple of minutes), you can sign up for a Vonage Account if you do not have one already <a href="https://vonage.dev/StrangerBuildsHack" target="_blank">here</a>.

You can add the coupon code given to you <a href="https://dashboard.vonage.com/coupons" target="_blank">here</a>

Once loaded completely, in the Codespace's terminal, you should see a set up script running asking for your `API key`. Complete the steps in the setup script. This will create an Application with Video functionality and create any Webhook endpoints needed.

> Note: You can get your credentials in the <a href="https://dashboard.vonage.com/settings" target="_blank">Vonage dashboard Settings Page</a>

If successful, you should see `APPLICATION READY` with a URL. Click the link to open in a new window or tab.

You should now have everything you need to complete the workshop:

- The workshop steps in the code editor
- all the files needed for the workshop
- application running in a separate tab

## Taking it further

In addition to creating the credentials needed for a Video Call, the server also has endpoints that can be used for [Archiving/Recording](https://developer.vonage.com/en/video/guides/archiving/overview), [Broadcasting](https://developer.vonage.com/en/video/guides/broadcast/overview),  [SIP calls](https://developer.vonage.com/en/video/guides/sip-interconnect), [Captions](https://developer.vonage.com/en/video/guides/live-caption), and [Audio Connector](https://developer.vonage.com/en/video/guides/audio-connector). Feel free to explore the different functionalities for your project.
